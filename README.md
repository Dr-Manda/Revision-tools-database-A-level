# Revision Tools Database (A-level) Pro

This repository serves as a centralized, interactive database for A-level revision tools, including a visual error tracker and logic maps.

## Features
- **Visual Error Ledger (SPA):** A modern Single Page Application built with Flask and Vanilla JS.
  - **Add:** Snap photos of questions and log mistakes with metadata.
  - **Dashboard:** Browse, search, and filter your mistakes by subject.
  - **Edit/Delete:** Update your actionable fixes or remove old entries.
- **SQLite Database:** Robust data storage with full CRUD support.
- **Logic Maps:** Structured markdown files for Maths and Further Maths topics.

## Getting Started
1. Run `python app.py`.
2. Access the tracker on your local network (e.g., `http://192.168.x.x:5000` on your iPhone).
